# فريق الـ Backend — Sub-agents لمشروع وكيل ماسة

هذا المجلد فيه خمسة sub-agents مخصّصين لتطوير الـ backend في Claude Code. كل واحد يعمل في نافذة سياق منفصلة بدور وأدوات محدّدة، فيبقى السياق الرئيسي نظيفاً وتتوزّع المهام.

## الوكلاء

| الوكيل | الدور | الأدوات | النموذج |
|---|---|---|---|
| **drizzle-schema-architect** | تصميم ومراجعة مخطط Postgres والهجرات (Drizzle) | كتابة + Bash | sonnet |
| **backend-api-engineer** | طبقة الاستعلام + Server Actions + zod + رفع الصور | كتابة + Bash | sonnet |
| **mastra-agent-engineer** | وكيل Mastra + الأدوات + الذاكرة + الرؤية | كتابة + Bash | sonnet |
| **backend-code-reviewer** | مراجعة الأمان والجودة (قراءة فقط) | قراءة + git | opus |
| **backend-tester** | كتابة وتشغيل اختبارات Vitest | كتابة + Bash | sonnet |

## كيف تستعملهم

- **تفويض تلقائي:** Claude Code يختار الوكيل المناسب حسب وصف المهمة تلقائياً.
- **استدعاء صريح:** اكتب مثلاً `use the drizzle-schema-architect subagent to add a discounts column`، أو نادِه بـ `@drizzle-schema-architect`.
- **الإدارة:** شغّل `/agents` داخل Claude Code لعرض الوكلاء وتعديلهم والتحقق من تحميلهم. Anthropic توصي بهذه الطريقة لإدارتهم.

## تنبيه مهم

إذا أضفت أو عدّلت ملف وكيل مباشرة على القرص، **أعد تشغيل جلسة Claude Code** لتحميله. الوكلاء المنشأون عبر واجهة `/agents` يُفعَّلون فوراً بلا إعادة تشغيل.

## ملاحظات

- الوكلاء يشرحون بالعربية إذا كتبت بالعربية، لكن الكود والمعرّفات تبقى بالإنجليزية.
- كل وكيل يحمل قواعد المشروع داخله (مفتاح is_published، تطبيع الألوان، حواجز عدم اختلاق الأسعار، أعمدة JOD بثلاث خانات عشرية...) فمخرجاته متّسقة مع بقية المشروع.
- تقدر تعدّل حقل `model` لأي وكيل (sonnet / opus / haiku / inherit) حسب التوازن بين الجودة والكلفة.
